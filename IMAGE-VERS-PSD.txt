--------------------------------------------------------------------------------
MISSION
--------------------------------------------------------------------------------
Fournir un script Photoshop (.jsx) téléchargeable qui recrée l'image en un document
PSD entièrement calqué et modifiable :
  1. Tous les textes en calques de texte modifiables (titres, dates, noms, adresses,
     prix, numéros…), recopiés mot pour mot.
  2. Formes, cadres, traits et dégradés en VECTEUR (calques de forme / remplissage :
     on change la couleur d'un double-clic).
  3. Icônes (Facebook, WhatsApp, YouTube, GPS, téléphone…) en VECTEUR via icon().
  4. Effets modifiables (styles de calque) : ombres, contours, lueurs.
  5. Photos et logos complexes en OBJETS DYNAMIQUES via image() (clic droit →
     Remplacer le contenu).
  6. Calques nommés en français et rangés par groupes (Fond, Décor, Photos, Titre,
     Infos, Contacts, Logos…).
Le script fonctionne pour N'IMPORTE QUELLE image : affiche, flyer, visuel réseaux
sociaux, bannière, carte de visite, menu, faire-part, logo, capture d'écran,
illustration, photo.

--------------------------------------------------------------------------------
ÉTAPE 1 — ANALYSE DE L'IMAGE
--------------------------------------------------------------------------------
1. Dimensions EXACTES en pixels (lis-les avec ton outil de code si tu en as un).
2. Identifie le type d'image et adapte la stratégie :
   • Affiche / flyer / visuel / bannière / carte / menu : décomposition complète
     (fond, décor, formes, photos, textes, icônes, logos).
   • Logo : reconstruis-le en vecteur (svgShape, polygon, ellipse, rect, text) ;
     ajoute aussi image('Logo original', …, {hidden:true}) pour comparaison.
   • Photo seule : image('Photo', [0,0,L,H]) ; si un sujet se détache nettement,
     ajoute au-dessus image('Sujet', [silhouette en 20 à 60 points]) ; puis les
     éventuels textes / logos posés sur la photo.
   • Capture d'écran / interface : rectangles arrondis, textes, icônes, photos.
   • Illustration : grandes zones de couleur en vecteur (svgShape / polygon),
     parties trop détaillées en image().
3. Liste TOUS les éléments, du plus éloigné (fond) au premier plan. Pour chacun :
   position et taille en pixels (x, y = coin haut-gauche), couleur(s) en #RRGGBB,
   opacité, coins arrondis, effets visibles (ombre, contour, lueur).
4. Textes : recopie exacte (accents, majuscules, ponctuation, retours à la ligne),
   un calque par bloc de même style ; taille en px (≈ hauteur des majuscules ÷ 0,7),
   alignement, interlignage, espacement des lettres, police la plus proche (nom
   PostScript, liste plus bas), maxWidth = largeur occupée dans l'image.
   Texte courbe ou très déformé : texte droit + note dans le nom du calque.
5. Icônes : utilise icon() avec la clé de la liste ICÔNES. Une icône absente de
   la liste → dessine-la avec svgShape() (tracé SVG 24×24 que tu connais) ou,
   à défaut, image().
6. Tout ce qui ne se dessine pas proprement en formes (personnes, objets, produits,
   paysages, textures, logos de marques complexes, QR codes) → image().
7. Vise la fidélité : 15 à 80 calques selon la richesse de l'image. N'oublie aucun
   texte, aucune icône.

ÉTAPE 2 — ÉCRITURE DE LA FONCTION DE CONSTRUCTION
--------------------------------------------------------------------------------
Écris un bloc de la forme :

run(function () {
    createDoc('Nom_calques', LARGEUR, HAUTEUR, '#couleurDeFond');
    loadReference();
    var fond = group('Fond');
    ... (appels dans l'ordre : du fond vers le premier plan) ...
    finish();
});

Règles :
- Chaque nouveau calque se place AU-DESSUS des précédents (dans son groupe).
  Crée les groupes dans l'ordre d'empilement voulu (le premier créé est en bas).
- JavaScript ancien (ExtendScript / ES3) UNIQUEMENT : var, function, for, if.
  INTERDIT : let, const, =>, `…${}`, forEach, map, filter, class, JSON.
- Dans les chaînes entre apostrophes, échappe les apostrophes : 'L\'Espace'.
  Retour à la ligne dans un texte : \n
- Coordonnées en pixels (entiers), dans le repère de l'image d'origine.

FONCTIONS DISPONIBLES   (fill = '#hex'  ou  { gradient: [['#hex', 0], ['#hex', 100]], angle: 90, radial: false })
  createDoc(nom, largeur, hauteur, fill)
  loadReference()                       ← charge l'image d'origine (intégrée au script)
  group(nom [, groupeParent])           → renvoie le groupe
  rect(nom, x, y, l, h, fill, o)        ← rectangle ; o.radius = coins arrondis
  ellipse(nom, x, y, l, h, fill, o)     ← cercle / ellipse
  gradient(nom, x, y, l, h, [['#hex', 0], ['#hex', 100]], angle, o)
        ← angle 90 = 1re couleur en bas → 2e en haut ; 0 = gauche → droite ;
          o.radial = true. Arrêt transparent : ['#hex', position, opacité 0-100]
  frame(nom, x, y, l, h, épaisseur, fill, o)    ← cadre vectoriel (o.radius)
  line(nom, x1, y1, x2, y2, épaisseur, fill, o) ← trait vectoriel
  polygon(nom, [[x,y], [x,y], ...], fill, o)    ← triangle, bandeau en biais…
  svgShape(nom, 'tracé SVG d', largeurVB, hauteurVB, x, y, l, h, fill, o)
        ← forme libre vectorielle (vagues, taches, flèches, logos simples)
  icon(nom, 'clé', x, y, taille, fill, o)       ← icône vectorielle (liste plus bas)
  text(nom, 'contenu', x, y, taille, 'PolicePostScript', '#hex', o)
        ← x,y = haut-gauche du texte ; o.align 'center' : x = centre ;
          'right' : x = bord droit
  image(nom, [x, y, l, h], o)   ou   image(nom, [[x,y], [x,y], ...], o)
        ← OBJET DYNAMIQUE repris de l'image d'origine ; liste de points =
          silhouette détourée (20 à 60 points) ; o.shape = 'ellipse' pour une
          photo ronde ; o.radius pour coins arrondis
  finish()

OPTIONS (o) — toutes facultatives
  group: g        opacity: 0-100      fillOpacity: 0-100      hidden: true
  blend: 'MULTIPLY' | 'SCREEN' | 'OVERLAY' | 'SOFTLIGHT' | 'LIGHTEN' | 'DARKEN' | 'COLORDODGE'
  shadow:      { color: '#000000', opacity: 50, angle: 120, distance: 8, size: 15, spread: 0 }
  innerShadow: { mêmes réglages }
  stroke:      { color: '#FFFFFF', size: 3, position: 'out' | 'in' | 'center', opacity: 100 }
  glow:        { color: '#FFD700', size: 20, opacity: 75, spread: 0 }     ← lueur externe
  innerGlow:   { mêmes réglages }                                         ← lueur interne
  Texte uniquement : align, tracking (ex. 50, 200), leading (interligne px),
    caps: true, bold: true, italic: true, underline: true, maxWidth: px,
    rotate: degrés, fallback: 'PolicePostScriptDeSecours'

import base64, io, struct
from PIL import Image

TXT = 'CHEMIN/VERS/IMAGE-VERS-PSD.txt'          # ce fichier d'instructions
IMG = 'CHEMIN/VERS/image_envoyee.jpg'           # l'image envoyée par l'utilisateur
OUT = 'DOSSIER/DE/SORTIE/nom_calques.jsx'       # le script à fournir

BUILD = r'''
run(function () {
    createDoc('Nom_calques', 1080, 1350, '#FFFFFF');
    loadReference();
    // ... tes calques ...
    finish();
});
'''

src = open(TXT, encoding='utf-8').read()
lib = src.rsplit('//@@LIB_START', 1)[1].split('//@@LIB_END')[0]
im = Image.open(IMG)
print('Taille image :', im.size)
buf = io.BytesIO()
if im.mode in ('RGBA', 'LA', 'P'):
    im.convert('RGBA').save(buf, 'PNG', optimize=True)
else:
    im.convert('RGB').save(buf, 'JPEG', quality=95)
b64 = base64.b64encode(buf.getvalue()).decode('ascii')
lib = lib.replace("var IMAGE_B64 = '';", "var IMAGE_B64 = '" + b64 + "';", 1)
code = '#target photoshop\n' + lib + '\n' + BUILD

def ascii_js(s):  # accents -> \uXXXX (lus correctement par Photoshop)
    out = []
    for ch in s:
        if ord(ch) < 128:
            out.append(ch)
        else:
            u = ch.encode('utf-16-le')
            out.extend('\\u%04x' % v for v in struct.unpack('<%dH' % (len(u) // 2), u))
    return ''.join(out)

open(OUT, 'w', encoding='ascii').write(ascii_js(code))
print('Script créé :', OUT)

app.bringToFront();

function cID(s) { return charIDToTypeID(s); }
function sID(s) { return stringIDToTypeID(s); }
function opt(o, k, d) { return (o && o[k] !== undefined && o[k] !== null) ? o[k] : d; }
function px(v) { return new UnitValue(v, 'px'); }
function deselect() { try { DOC.selection.deselect(); } catch (e) {} }
function hex2rgb(h) {
    h = String(h).replace('#', '');
    if (h.length == 3) { h = h.charAt(0) + h.charAt(0) + h.charAt(1) + h.charAt(1) + h.charAt(2) + h.charAt(2); }
    return [parseInt(h.substr(0, 2), 16), parseInt(h.substr(2, 2), 16), parseInt(h.substr(4, 2), 16)];
}
function solid(h) { var c = new SolidColor(), r = hex2rgb(h); c.rgb.red = r[0]; c.rgb.green = r[1]; c.rgb.blue = r[2]; return c; }
function rgbDesc(h) {
    var r = hex2rgb(h), d = new ActionDescriptor();
    d.putDouble(cID('Rd  '), r[0]); d.putDouble(cID('Grn '), r[1]); d.putDouble(cID('Bl  '), r[2]);
    return d;
}
function inArr(a, v) { for (var i = 0; i < a.length; i++) { if (a[i] == v) { return true; } } return false; }

// ---------- Placement dans le groupe + options communes ----------
function place(l, o) {
    var g = opt(o, 'group', null);
    try {
        if (g) {
            if (g.layers.length > 0) { l.move(g.layers[0], ElementPlacement.PLACEBEFORE); }
            else { l.move(g, ElementPlacement.INSIDE); }
        } else { l.move(DOC.layers[0], ElementPlacement.PLACEBEFORE); }
    } catch (e) {}
    if (opt(o, 'opacity', null) !== null) { try { l.opacity = o.opacity; } catch (e1) {} }
    if (opt(o, 'fillOpacity', null) !== null) { try { l.fillOpacity = o.fillOpacity; } catch (e2) {} }
    if (opt(o, 'blend', null)) { try { l.blendMode = BlendMode[o.blend]; } catch (e3) {} }
    if (o && (o.shadow || o.innerShadow || o.stroke || o.glow || o.innerGlow)) { effects(l, o); }
    if (opt(o, 'hidden', false)) { l.visible = false; }
    COUNT++;
    return l;
}

// ---------- Styles de calque modifiables : ombres, contour, lueurs ----------
function effects(l, o) {
    try {
        DOC.activeLayer = l;
        var d = new ActionDescriptor(), r = new ActionReference(), fx = new ActionDescriptor();
        r.putProperty(cID('Prpr'), cID('Lefx')); r.putEnumerated(cID('Lyr '), cID('Ordn'), cID('Trgt'));
        d.putReference(cID('null'), r);
        fx.putUnitDouble(cID('Scl '), cID('#Prc'), 100);
        function shadow(s, key, inner) {
            var ds = new ActionDescriptor();
            ds.putBoolean(cID('enab'), true);
            ds.putEnumerated(cID('Md  '), cID('BlnM'), cID('Mltp'));
            ds.putObject(cID('Clr '), cID('RGBC'), rgbDesc(opt(s, 'color', '#000000')));
            ds.putUnitDouble(cID('Opct'), cID('#Prc'), opt(s, 'opacity', inner ? 40 : 50));
            ds.putBoolean(cID('uglg'), false);
            ds.putUnitDouble(cID('lagl'), cID('#Ang'), opt(s, 'angle', 120));
            ds.putUnitDouble(cID('Dstn'), cID('#Pxl'), opt(s, 'distance', inner ? 4 : 8));
            ds.putUnitDouble(cID('Ckmt'), cID('#Pxl'), opt(s, 'spread', 0));
            ds.putUnitDouble(cID('blur'), cID('#Pxl'), opt(s, 'size', inner ? 8 : 15));
            fx.putObject(cID(key), cID(key), ds);
        }
        function glow(s, key, inner) {
            var gd = new ActionDescriptor();
            gd.putBoolean(cID('enab'), true);
            gd.putEnumerated(cID('Md  '), cID('BlnM'), cID(opt(s, 'blend', 'screen') == 'normal' ? 'Nrml' : 'Scrn'));
            gd.putObject(cID('Clr '), cID('RGBC'), rgbDesc(opt(s, 'color', '#FFFFFF')));
            gd.putUnitDouble(cID('Opct'), cID('#Prc'), opt(s, 'opacity', 75));
            gd.putEnumerated(cID('GlwT'), cID('BETE'), cID('SfBL'));
            gd.putUnitDouble(cID('Ckmt'), cID('#Pxl'), opt(s, 'spread', 0));
            gd.putUnitDouble(cID('blur'), cID('#Pxl'), opt(s, 'size', 20));
            gd.putUnitDouble(cID('Nose'), cID('#Prc'), 0);
            gd.putUnitDouble(cID('ShdN'), cID('#Prc'), 0);
            gd.putBoolean(cID('AntA'), true);
            gd.putUnitDouble(cID('Inpr'), cID('#Prc'), 50);
            if (inner) { gd.putEnumerated(cID('glwS'), cID('IGSr'), cID('SrcE')); }
            fx.putObject(cID(key), cID(key), gd);
        }
        if (o.shadow) { shadow(o.shadow, 'DrSh', false); }
        if (o.innerShadow) { shadow(o.innerShadow, 'IrSh', true); }
        if (o.glow) { glow(o.glow, 'OrGl', false); }
        if (o.innerGlow) { glow(o.innerGlow, 'IrGl', true); }
        if (o.stroke) {
            var k = o.stroke, st = new ActionDescriptor(), pos = opt(k, 'position', 'out');
            st.putBoolean(cID('enab'), true);
            st.putEnumerated(cID('Styl'), cID('FStl'), cID(pos == 'in' ? 'InsF' : (pos == 'center' ? 'CtrF' : 'OutF')));
            st.putEnumerated(cID('PntT'), cID('FrFl'), cID('SClr'));
            st.putEnumerated(cID('Md  '), cID('BlnM'), cID('Nrml'));
            st.putUnitDouble(cID('Opct'), cID('#Prc'), opt(k, 'opacity', 100));
            st.putUnitDouble(cID('Sz  '), cID('#Pxl'), opt(k, 'size', 2));
            st.putObject(cID('Clr '), cID('RGBC'), rgbDesc(opt(k, 'color', '#000000')));
            fx.putObject(cID('FrFX'), cID('FrFX'), st);
        }
        d.putObject(cID('T   '), cID('Lefx'), fx);
        executeAction(cID('setd'), d, DialogModes.NO);
    } catch (e) {}
}

// ---------- Remplissages : couleur unie '#hex' ou dégradé {gradient:[...], angle, radial} ----------
function gradDesc(f) {
    var stops = f.gradient, g = new ActionDescriptor(), gr = new ActionDescriptor(), cl = new ActionList(), tl = new ActionList(), i;
    g.putUnitDouble(cID('Angl'), cID('#Ang'), opt(f, 'angle', 90));
    g.putEnumerated(cID('Type'), cID('GrdT'), cID(opt(f, 'radial', false) ? 'Rdl ' : 'Lnr '));
    if (opt(f, 'scale', null) !== null) { g.putUnitDouble(cID('Scl '), cID('#Prc'), f.scale); }
    gr.putString(cID('Nm  '), 'Dégradé');
    gr.putEnumerated(cID('GrdF'), cID('GrdF'), cID('CstS'));
    gr.putDouble(cID('Intr'), 4096);
    for (i = 0; i < stops.length; i++) {
        var s = new ActionDescriptor(), t = new ActionDescriptor(), loc = Math.round(opt(stops[i], 1, i * 100 / Math.max(1, stops.length - 1)) * 40.96);
        s.putObject(cID('Clr '), cID('RGBC'), rgbDesc(stops[i][0]));
        s.putEnumerated(cID('Type'), cID('Clry'), cID('UsrS'));
        s.putInteger(cID('Lctn'), loc); s.putInteger(cID('Mdpn'), 50);
        cl.putObject(cID('Clrt'), s);
        t.putUnitDouble(cID('Opct'), cID('#Prc'), opt(stops[i], 2, 100));
        t.putInteger(cID('Lctn'), loc); t.putInteger(cID('Mdpn'), 50);
        tl.putObject(cID('TrnS'), t);
    }
    gr.putList(cID('Clrs'), cl); gr.putList(cID('Trns'), tl);
    g.putObject(cID('Grad'), cID('Grdn'), gr);
    return g;
}
// Crée un calque de remplissage (couleur ou dégradé), avec une forme native si shp est donné
function fillLayer(fill, shp) {

}

// ---------- Tracés vectoriels ----------
// polys : [[ [x,y], [x,y], ... ], ...] — plusieurs contours ; les contours intérieurs font des trous
function makePath(polys) {
    var spis = [], k, j;
    for (k = 0; k < polys.length; k++) {
        var pts = [];
        for (j = 0; j < polys[k].length; j++) {
            var pp = new PathPointInfo();
            pp.kind = PointKind.CORNERPOINT;
            pp.anchor = [polys[k][j][0], polys[k][j][1]];
            pp.leftDirection = pp.anchor; pp.rightDirection = pp.anchor;
            pts.push(pp);
        }
        var sp = new SubPathInfo();
        sp.closed = true;
        sp.operation = k == 0 ? ShapeOperation.SHAPEADD : ShapeOperation.SHAPEXOR;
        sp.entireSubPath = pts;
        spis.push(sp);
    }
    return DOC.pathItems.add('tmp_' + COUNT + '_' + new Date().getTime(), spis);
}
// Ajoute un masque vectoriel (polys) au calque l
function vectorMask(l, polys) {
    DOC.activeLayer = l;
    var p = makePath(polys);
    try {
        p.select();
        var d = new ActionDescriptor(), r = new ActionReference(), r2 = new ActionReference(), r3 = new ActionReference();
        r.putClass(cID('Path')); d.putReference(cID('null'), r);
        r2.putEnumerated(cID('Path'), cID('Path'), sID('vectorMask')); d.putReference(cID('At  '), r2);
        r3.putEnumerated(cID('Path'), cID('Ordn'), cID('Trgt')); d.putReference(cID('Usng'), r3);
        executeAction(cID('Mk  '), d, DialogModes.NO);
    } catch (e) {}
    try { p.remove(); } catch (e2) {}
    DOC.activeLayer = l;
    return l;
}
// Calque de forme vectorielle à partir de contours
function pathShape(name, polys, fill, o) {
    var l = fillLayer(fill, null);
    vectorMask(l, polys);
    l.name = name;
    return place(l, o);
}
function roundRectD(x, y, w, h, r) {
    r = Math.max(0, Math.min(r, w / 2, h / 2));
    if (r == 0) { return 'M' + x + ' ' + y + 'H' + (x + w) + 'V' + (y + h) + 'H' + x + 'Z'; }
    return 'M' + (x + r) + ' ' + y + 'H' + (x + w - r) + 'A' + r + ' ' + r + ' 0 0 1 ' + (x + w) + ' ' + (y + r) +
        'V' + (y + h - r) + 'A' + r + ' ' + r + ' 0 0 1 ' + (x + w - r) + ' ' + (y + h) +
        'H' + (x + r) + 'A' + r + ' ' + r + ' 0 0 1 ' + x + ' ' + (y + h - r) +
        'V' + (y + r) + 'A' + r + ' ' + r + ' 0 0 1 ' + (x + r) + ' ' + y + 'Z';
}
function ellipseD(x, y, w, h) {
    var rx = w / 2, ry = h / 2;
    return 'M' + x + ' ' + (y + ry) + 'A' + rx + ' ' + ry + ' 0 1 1 ' + (x + w) + ' ' + (y + ry) + 'A' + rx + ' ' + ry + ' 0 1 1 ' + x + ' ' + (y + ry) + 'Z';
}
function polysOf(d) { return svgPolys(d, 1, 1, 0, 0, 0.75); }

// Décodage base64 (image intégrée au script)
function b64decode(s) {
    var k = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/', m = {}, i, out = [], ch = [], a, b, c, e;
    for (i = 0; i < 64; i++) { m[k.charAt(i)] = i; }
    s = s.replace(/[^A-Za-z0-9+\/]/g, '');
    for (i = 0; i + 3 < s.length + 3; i += 4) {
        a = m[s.charAt(i)]; b = m[s.charAt(i + 1)]; c = m[s.charAt(i + 2)]; e = m[s.charAt(i + 3)];
        if (a === undefined || b === undefined) { break; }
        ch.push(String.fromCharCode((a << 2) | (b >> 4)));
        if (c !== undefined) { ch.push(String.fromCharCode(((b & 15) << 4) | (c >> 2))); }
        if (e !== undefined) { ch.push(String.fromCharCode(((c & 3) << 6) | e)); }
        if (ch.length > 30000) { out.push(ch.join('')); ch = []; }
    }
    out.push(ch.join(''));
    return out.join('');
}

// ---------- Formes vectorielles ----------
// fill = '#hex' ou { gradient: [['#hex', 0], ['#hex', 100]], angle: 90, radial: false }
function rect(name, x, y, w, h, fill, o) {
    if (opt(o, 'radius', 0) > 0) { return pathShape(name, polysOf(roundRectD(x, y, w, h, o.radius)), fill, o); }
    var l;
    try { l = fillLayer(fill, { kind: 'rect', x: x, y: y, w: w, h: h }); l.name = name; return place(l, o); }
    catch (e) { return pathShape(name, polysOf(roundRectD(x, y, w, h, 0)), fill, o); }
}
function ellipse(name, x, y, w, h, fill, o) {
    var l;
    try { l = fillLayer(fill, { kind: 'ellipse', x: x, y: y, w: w, h: h }); l.name = name; return place(l, o); }
    catch (e) { return pathShape(name, polysOf(ellipseD(x, y, w, h)), fill, o); }
}
function gradient(name, x, y, w, h, stops, angle, o) {
    var f = { gradient: stops, angle: angle, radial: opt(o, 'radial', false) };
    return rect(name, x, y, w, h, f, o);
}
// Cadre (contour vectoriel) : épaisseur thick, coins arrondis avec o.radius
function frame(name, x, y, w, h, thick, fill, o) {
    var r = opt(o, 'radius', 0);
    var outer = polysOf(roundRectD(x, y, w, h, r)), inner = polysOf(roundRectD(x + thick, y + thick, w - 2 * thick, h - 2 * thick, Math.max(0, r - thick)));
    return pathShape(name, outer.concat(inner), fill, o);
}
function polygon(name, pts, fill, o) { return pathShape(name, [pts], fill, o); }
function line(name, x1, y1, x2, y2, thick, fill, o) {
    var dx = x2 - x1, dy = y2 - y1, len = Math.sqrt(dx * dx + dy * dy) || 1;
    var nx = -dy / len * thick / 2, ny = dx / len * thick / 2;
    return polygon(name, [[x1 + nx, y1 + ny], [x2 + nx, y2 + ny], [x2 - nx, y2 - ny], [x1 - nx, y1 - ny]], fill, o);
}
// Forme libre en tracé SVG (attribut d), dessinée dans une boîte vbW×vbH puis placée en x,y,w,h
function svgShape(name, d, vbW, vbH, x, y, w, h, fill, o) {
    return pathShape(name, svgPolys(d, w / vbW, h / vbH, x, y, 0.75), fill, o);
}
// Icône vectorielle de la bibliothèque ICONS (carré size×size)
function icon(name, key, x, y, size, fill, o) {
    var d = ICONS[String(key).toLowerCase()];
    if (!d) {
        if (!inArr(MISSING_ICONS, key)) { MISSING_ICONS.push(key); }
        return ellipse(name + ' (icône ' + key + ' à remplacer)', x, y, size, size, fill, o);
    }
    return svgShape(name, d, 24, 24, x, y, size, size, fill, o);
}

    deselect();

    t.contents = String(content).replace(/\n/g, '\r');

        if (!inArr(MISSING_FONTS, font)) { MISSING_FONTS.push(font); }
        var fb = opt(o, 'fallback', /black|heavy|extrabold|ultra/i.test(font) ? 'Arial-Black' : (/bold|semibold|demi/i.test(font) ? 'Arial-BoldMT' : 'ArialMT'));
        try { app.fonts.getByName(fb); t.font = fb; } catch (e2) { try { t.font = 'ArialMT'; } catch (e3) {} }
    }
    t.size = px(size);
    t.color = solid(color);
    var al = opt(o, 'align', 'left');
    t.justification = al == 'center' ? Justification.CENTER : (al == 'right' ? Justification.RIGHT : Justification.LEFT);
    if (opt(o, 'tracking', null) !== null) { t.tracking = o.tracking; }
    if (opt(o, 'leading', null) !== null) { t.useAutoLeading = false; t.leading = px(o.leading); }

    if (opt(o, 'underline', false)) { t.underline = UnderlineType.UNDERLINELEFT; }
    t.position = [px(x), px(y + size)];
    try {
        var b = l.bounds, L = b[0].as('px'), T = b[1].as('px'), R = b[2].as('px');
        if (opt(o, 'maxWidth', 0) > 0 && R - L > o.maxWidth) {
            var sc = o.maxWidth / (R - L) * 100;
            l.resize(sc, sc, AnchorPosition.TOPLEFT);
            b = l.bounds; L = b[0].as('px'); T = b[1].as('px'); R = b[2].as('px');
        }
        var ax = al == 'center' ? (L + R) / 2 : (al == 'right' ? R : L);
        l.translate(px(x - ax), px(y - T));
        if (opt(o, 'rotate', 0)) { l.rotate(o.rotate, AnchorPosition.MIDDLECENTER); }
    } catch (e4) {}
    return place(l, o);
}

// ---------- Photos / logos en OBJETS DYNAMIQUES ----------
// zone : [x, y, w, h]  ou  [[x,y], [x,y], ...] (silhouette détourée)
// o.shape : 'rect' (défaut) | 'ellipse' (photo ronde) ; o.radius : coins arrondis
// Clic droit sur le calque > Remplacer le contenu… pour mettre sa propre photo.
function image(name, zone, o) {
    deselect();
    var poly = null, x, y, w, h, i;
    if (typeof zone[0] == 'number') { x = zone[0]; y = zone[1]; w = zone[2]; h = zone[3]; }
    else {
        poly = zone; var x2 = -1e9, y2 = -1e9; x = 1e9; y = 1e9;
        for (i = 0; i < zone.length; i++) { x = Math.min(x, zone[i][0]); y = Math.min(y, zone[i][1]); x2 = Math.max(x2, zone[i][0]); y2 = Math.max(y2, zone[i][1]); }
        w = x2 - x; h = y2 - y;
    }
    var W = DOC.width.as('px'), H = DOC.height.as('px');
    var bx = Math.max(0, Math.round(x)), by = Math.max(0, Math.round(y));
    var bw = Math.min(W, Math.round(x + w)) - bx, bh = Math.min(H, Math.round(y + h)) - by;
    var box = [[bx, by], [bx + bw, by], [bx + bw, by + bh], [bx, by + bh]];
    var l;
    if (REF) {
        l = REF.duplicate(); l.visible = true; DOC.activeLayer = l;
        DOC.selection.select(box); DOC.selection.invert(); DOC.selection.clear(); deselect();
    } else {
        l = DOC.artLayers.add(); DOC.activeLayer = l;
        DOC.selection.select(box); DOC.selection.fill(solid('#BDBDBD')); deselect();
    }
    l.name = name;
    try { executeAction(sID('newPlacedLayer'), new ActionDescriptor(), DialogModes.NO); l = DOC.activeLayer; l.name = name; } catch (e) {}
    var shp = opt(o, 'shape', 'rect');
    if (poly) { vectorMask(l, [poly]); }
    else if (shp == 'ellipse') { vectorMask(l, polysOf(ellipseD(x, y, w, h))); }
    else if (opt(o, 'radius', 0) > 0) { vectorMask(l, polysOf(roundRectD(x, y, w, h, o.radius))); }
    return place(l, o);
}

// ---------- Lecture d'un tracé SVG (attribut d) → contours vectoriels ----------
// Renvoie [[ [x,y], [x,y], ... ], ...] (un tableau de points par sous-tracé),
// mis à l'échelle (sx, sy) et décalé (ox, oy). Les courbes sont converties en
// segments très courts (tol = longueur max d'un segment en px).
function svgPolys(d, sx, sy, ox, oy, tol) {
    var s = String(d), i = 0, n = s.length, polys = [], cur = null;
    var cx = 0, cy = 0, stx = 0, sty = 0, lcx = 0, lcy = 0, lq = null, lc = null, cmd = '', prev = '';
    tol = tol || 1;
    var sc = Math.max(Math.abs(sx), Math.abs(sy));
    function ws() { while (i < n && /[\s,]/.test(s.charAt(i))) { i++; } }
    function num() {
        ws();
        var m = s.substr(i, 40).match(/^[-+]?(?:\d*\.\d+|\d+\.?\d*)(?:[eE][-+]?\d+)?/);
        if (!m) { throw new Error('SVG: nombre attendu à la position ' + i); }
        i += m[0].length;
        return parseFloat(m[0]);
    }
    function flag() { ws(); var c = s.charAt(i); i++; return c == '1' ? 1 : 0; }
    function hasNum() { ws(); return i < n && /[-+.\d]/.test(s.charAt(i)); }
    function out(x, y) { cur.push([ox + x * sx, oy + y * sy]); }
    function moveTo(x, y) {
        cur = []; polys.push(cur); out(x, y);
        cx = stx = x; cy = sty = y;
    }
    function lineTo(x, y) { if (!cur) { moveTo(cx, cy); } out(x, y); cx = x; cy = y; }
    function cubic(x1, y1, x2, y2, x, y) {
        if (!cur) { moveTo(cx, cy); }
        var len = (Math.sqrt((x1 - cx) * (x1 - cx) + (y1 - cy) * (y1 - cy)) + Math.sqrt((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1)) + Math.sqrt((x - x2) * (x - x2) + (y - y2) * (y - y2))) * sc;
        var k = Math.max(2, Math.min(200, Math.ceil(len / tol))), t, u, j;
        for (j = 1; j <= k; j++) {
            t = j / k; u = 1 - t;
            out(u * u * u * cx + 3 * u * u * t * x1 + 3 * u * t * t * x2 + t * t * t * x,
                u * u * u * cy + 3 * u * u * t * y1 + 3 * u * t * t * y2 + t * t * t * y);
        }
        cx = x; cy = y;
    }
    function quad(qx, qy, x, y) {
        cubic(cx + 2 / 3 * (qx - cx), cy + 2 / 3 * (qy - cy), x + 2 / 3 * (qx - x), y + 2 / 3 * (qy - y), x, y);
    }
    function arc(rx, ry, rot, large, sweep, x, y) {
        if (!cur) { moveTo(cx, cy); }
        var x0 = cx, y0 = cy;
        rx = Math.abs(rx); ry = Math.abs(ry);
        if (rx == 0 || ry == 0 || (x0 == x && y0 == y)) { lineTo(x, y); return; }
        var phi = rot * Math.PI / 180, cp = Math.cos(phi), sp = Math.sin(phi);
        var dx = (x0 - x) / 2, dy = (y0 - y) / 2;
        var x1p = cp * dx + sp * dy, y1p = -sp * dx + cp * dy;
        var lam = (x1p * x1p) / (rx * rx) + (y1p * y1p) / (ry * ry);
        if (lam > 1) { var sl = Math.sqrt(lam); rx *= sl; ry *= sl; }
        var num2 = rx * rx * ry * ry - rx * rx * y1p * y1p - ry * ry * x1p * x1p;
        var den = rx * rx * y1p * y1p + ry * ry * x1p * x1p;
        var co = Math.sqrt(Math.max(0, num2 / den)) * (large == sweep ? -1 : 1);
        var cxp = co * rx * y1p / ry, cyp = -co * ry * x1p / rx;
        var ccx = cp * cxp - sp * cyp + (x0 + x) / 2, ccy = sp * cxp + cp * cyp + (y0 + y) / 2;
        function ang(ux, uy, vx, vy) {
            var a = Math.atan2(ux * vy - uy * vx, ux * vx + uy * vy);
            return a;
        }
        var t1 = ang(1, 0, (x1p - cxp) / rx, (y1p - cyp) / ry);
        var dt = ang((x1p - cxp) / rx, (y1p - cyp) / ry, (-x1p - cxp) / rx, (-y1p - cyp) / ry);
        if (!sweep && dt > 0) { dt -= 2 * Math.PI; } else if (sweep && dt < 0) { dt += 2 * Math.PI; }
        var len = Math.abs(dt) * Math.max(rx, ry) * sc;
        var k = Math.max(2, Math.min(200, Math.ceil(len / tol))), j, a;
        for (j = 1; j <= k; j++) {
            a = t1 + dt * j / k;
            out(cp * rx * Math.cos(a) - sp * ry * Math.sin(a) + ccx, sp * rx * Math.cos(a) + cp * ry * Math.sin(a) + ccy);
        }
        cx = x; cy = y;
    }
    while (true) {
        ws();
        if (i >= n) { break; }
        var ch = s.charAt(i);
        if (/[a-zA-Z]/.test(ch)) { cmd = ch; i++; }
        else if (!cmd) { throw new Error('SVG: commande attendue'); }
        var rel = cmd == cmd.toLowerCase(), C = cmd.toUpperCase(), bx = rel ? cx : 0, by = rel ? cy : 0;
        var x1, y1, x2, y2, x, y;
        if (C == 'Z') {
            cx = stx; cy = sty; cur = null; lq = lc = null; prev = 'Z';
            continue;
        }
        if (C == 'M') { moveTo(bx + num(), by + num()); cmd = rel ? 'l' : 'L'; lq = lc = null; prev = 'M'; continue; }
        if (C == 'L') { x = bx + num(); y = by + num(); lineTo(x, y); lq = lc = null; }
        else if (C == 'H') { lineTo(bx + num(), cy); lq = lc = null; }
